## Задания

### Задание 1 — Доработка класса UnorderedList (3 балла)

**Файл:** `ex1.py`

Взята базовая реализация класса `UnorderedList` из лекционных материалов и доработана:

1. **Реализованы методы:**
   - `append(item)` — добавление элемента в конец списка.
   - `index(item)` — возврат позиции элемента (или `ValueError`).
   - `insert(pos, item)` — вставка элемента на заданную позицию.
   - `pop(pos=-1)` — удаление и возврат элемента (по умолчанию последнего).
2. **Метод `__str__`** — вывод содержимого списка в Python-стиле: `[1, 2, 3]`.
3. **Метод `slice(start, stop)`** — возвращает копию списка с позиции `start` до `stop` (не включая).

Все методы протестированы.

### Задание 2 — Стратегия «сдвиг в начало» (2 балла)

**Файл:** `ex2.py`

Функция `move_to_front(n)` читает `n` строк с клавиатуры и сохраняет их в связном списке без повторов. Логика:

- Если строка встречается впервые — она вставляется в начало списка.
- Если строка уже есть в списке — она удаляется и снова вставляется в начало.

Такая стратегия применяется в кешировании и сжатии данных.

### Задание 3 — Обращение связного списка (2 балла)

**Файл:** `ex3.py`

Реализованы две функции обращения порядка элементов односвязного списка с разрушением исходного:

- **`reverse_iterative(head)`** — итеративный алгоритм с тремя указателями (`prev`, `current`, `next_node`).
- **`reverse_recursive(head, prev=None)`** — рекурсивный алгоритм, возвращающий новый первый узел.

**Сложность обеих реализаций:** `O(N)` по времени, `O(1)` по памяти (для итеративной).

### Задание 4 — Стек, очередь, дек на базе UnorderedList (3 балла)

**Файл:** `ex4.py`

На основе класса `UnorderedList` из задания 1 реализованы три линейные структуры:

1. **`StackUL`** — стек: `push`, `pop`, `is_empty`.
2. **`QueueUL`** — очередь: `enqueue`, `dequeue`, `is_empty`.
3. **`DequeUL`** — дек: `add_front`, `add_rear`, `remove_front`, `remove_rear`, `is_empty`.

**Эксперимент:**  
Проведено сравнение производительности очереди на встроенном списке Python и на связном списке. Операция `pop(0)` у встроенного списка имеет сложность `O(N)`, тогда как удаление из начала связного списка — `O(1)`. При `N = 2000` разница становится заметной.

### Задание 5 — Класс DoubleList (2 балла)

**Файл:** `ex5.py`

Реализован класс `DoubleList` для двусвязного списка. Каждый узел (`DoubleNode`) содержит ссылки на предыдущий и следующий элементы.

**Методы класса:**

| Метод | Назначение |
|-------|------------|
| `is_empty()` | Проверка списка на пустоту |
| `size()` | Количество элементов |
| `search(item)` | Поиск узла по значению |
| `insert_front(item)` | Вставка в начало |
| `insert_rear(item)` | Вставка в конец |
| `delete_front()` | Удаление из начала |
| `delete_rear()` | Удаление из конца |
| `insert_before(node, item)` | Вставка перед указанным узлом |
| `insert_after(node, item)` | Вставка после указанного узла |
| `delete_node(node)` | Удаление указанного узла |

Все методы протестированы.

### Задание 6 — Проверка HTML-тегов стеком (2 балла)

**Файл:** `ex6.py`

Программа проверяет сбалансированность открывающих и закрывающих HTML-тегов с помощью стека. Алгоритм основан на проверке скобочной последовательности из лекционных материалов.

**Логика:**
- Открывающий тег → помещается в стек.
- Закрывающий тег → сравнивается с вершиной стека; при несовпадении — ошибка.
- В конце стек должен быть пуст.

**Используемые средства:** класс `Stack`, регулярные выражения (`re`) для извлечения тегов.

### Задание 7 — Стековый калькулятор (2 балла)

**Файл:** `ex7.py`

Реализован стековый калькулятор, вычисляющий выражения в обратной польской нотации (ОПН, постфиксная форма).

**Правила:**
- Число → помещается в стек.
- Оператор (`+`, `-`, `*`, `/`) → из стека извлекаются два числа, выполняется операция, результат возвращается в стек.
- После обработки всех токенов в стеке должно остаться одно число.

**Обработка ошибок:**
- Недостаточно операндов для операции.
- Некорректный токен (не число и не оператор).
- В стеке осталось больше одного числа.

### Задание 8 — Симуляция автомойки (вариант 1, 4 балла)

**Файл:** `ex8.py`

Имитационное моделирование очереди машин на автомойке с использованием структуры данных «очередь».

**Предположения симуляции:**
1. Симуляция длится 120 минут (7200 секунд).
2. Каждую минуту с вероятностью 10% приезжает новая машина.
3. Время на мойку одной машины — 10 минут.

**Структуры:**
- `Queue` — очередь машин, ожидающих мойку.
- `CarWash` — модель автомойки (занята / свободна, остаток времени).
- `Car` — машина с временной меткой прибытия.

**Результат:**  
Выводится среднее время ожидания машин в очереди и количество машин, оставшихся в очереди к концу симуляции.

**Используемые библиотеки:** `random`

## Примечания

- Все структуры данных реализованы с нуля, без использования встроенных коллекций Python (`list`, `collections.deque` и т.п.) там, где это требуется по заданию.
- Для сравнения производительности используется `time.time()`.
- Рекурсивные реализации (`reverse_recursive`) ограничены глубиной рекурсии Python; для больших списков предпочтительна итеративная версия.
- Классы `Stack`, `Queue`, `Deque` в задании 4 намеренно названы с суффиксом `UL`, чтобы отличать их от встроенных и лекционных реализаций.
